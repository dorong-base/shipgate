# Enforcement Rules — the guardian's checklist

> `agents/brand-guardian.md` scores every output against this list. Start with these 8; add a rule ONLY when a real failure repeats twice. Rules born from real failures stick; rules born from imagination rot.

1. **Voice match** — sounds like the person in `voice-guide.md`, not like a press release
2. **Vocabulary** — every "we say / we never say" swap applied
3. **Lead with what's possible** — the reader's outcome in the first line, not the product or the problem
4. **Only verified claims** — every number, customer story, and capability traces to a real source. No source = cut
5. **One message per piece** — if it argues two things, it's two pieces
6. **Active voice, second person** — the reader does things; the product doesn't "empower" them
7. **No AI tells** — no "In today's fast-paced world", no rule-of-three cadence, no "It's not X, it's Y" contrast framing
8. **CTA is an action** — a verb the reader can do now, never "Learn more"

## Scoring

- **9–10** — release
- **7–8** — guardian fixes inline, then release
- **below 7** — back to the writer with the failing rule numbers

## The learning loop (this is the whole system)

When a human rejects something the guardian passed: write the reason here as a candidate rule. Second occurrence → it becomes a numbered rule. The checklist is a memory of every mistake you refuse to make twice.
