# The AI Marketing Stack Scorecard
### Score your AI stack in 4 minutes. Know which layer to build next.

From the AI Marketing Engineering talk — Ofer Blutrich, Base44.
Microsoft's marketing org runs 12 agents. Mine runs 12. Yours can too — one layer at a time.

---

## How to use this

Score each layer 1-5. Be honest — the lowest score is your next build, and the build order at the bottom tells you where to start. Total under 12: you have tools, not infrastructure. That's fine. Now you know.

## 🧠 Layer 1 — Brain (how it thinks)

| Score | Where you are |
|---|---|
| 1 | One ChatGPT tab, prompts from memory |
| 2 | A saved prompt library the team sometimes uses |
| 3 | Specialist agents per task (writer, reviewer, researcher) |
| 4 | Agents load your brand canon before they can start working |
| 5 | Structural enforcement: agents physically cannot skip the rules, and a gate scores every output before it leaves |

**Graduate by:** taking your brand voice out of people's heads and into a file every agent must read first.

## 👁 Layer 2 — Visibility (how the org sees it)

| Score | Where you are |
|---|---|
| 1 | AI output lives in personal chats — nobody else sees it |
| 2 | Outputs pasted into Slack when someone remembers |
| 3 | A shared folder or doc of AI-generated assets |
| 4 | One screen with status per asset (draft / review / approved) |
| 5 | Stakeholders open a live board and see everything the AI did this week — without asking you |

**Graduate by:** giving every AI asset a status and a reviewer, on one page anyone can open.

## 🦿 Layer 3 — Movement (what it actually does)

| Score | Where you are |
|---|---|
| 1 | AI writes text; a human copies, pastes, publishes |
| 2 | AI fills templates; a human still runs every step |
| 3 | One-click actions: the human approves, the system executes |
| 4 | Event-triggered chains: one event fires a multi-step flow |
| 5 | Agents act end-to-end through APIs and schedulers — the team opens the morning to finished material |

**Graduate by:** picking ONE recurring task and wiring it to run on a trigger instead of a request.

## 💾 Layer 4 — Memory (what survives between runs)

| Score | Where you are |
|---|---|
| 1 | Every session starts from zero |
| 2 | Some context pasted in from old chats |
| 3 | A living context file agents read at start |
| 4 | Automatic history: every asset gets a record written by the system, not by a person |
| 5 | Digests with targets: the system knows where you are vs goal vs last week — and gets smarter every cycle |

**Graduate by:** making the system write its own history — a hook that logs every run, so nobody has to remember to.

---

## Build order (most teams get this wrong)

1. **Visibility first** — you need trust before autonomy
2. **Memory second** — cheap, compounds from day one
3. **Brain third** — specialists, once you know what to measure
4. **Movement last** — only let it act on what you already trust

## The one action for this week

Write down 3 things your AI does today. For each: which layer does it live in, and what one thing is missing to graduate it to the next score?
